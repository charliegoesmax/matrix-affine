# LogSeq starter graph

This is a minimal Logseq graph skeleton for the matrix-affine stack.

## Recommended plugins (install via Marketplace after first open)

1. **Agenda** (logseq-plugin-agenda) — calendar, tasks, projects, Pomodoro
2. **Heatmap** (logseq-plugin-heatmap) — journal activity heatmap
3. **Journals Calendar** (logseq-journals-calendar) — quick calendar navigation
4. **Bullet Threading** — visual nesting lines
5. **Full House** or similar template plugin — better templates for BookStack exports

### How to install
- Open this graph in Logseq (select the folder).
- Settings → Advanced → Developer mode ON (if needed).
- Plugins → Marketplace → search and install the above.
- Plugins are stored per-device in `~/.logseq` (not inside the graph). This keeps the graph portable.

## Structure
- `pages/` — your notes
- `journals/` — daily journals
- `logseq/` — config, custom.css, etc.

Feel free to delete this README after setup.
